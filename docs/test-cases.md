# Тестирование (материалы для раздела 4.3)

Тестирование выполнено на двух уровнях.

1. **Автоматические тесты:** 158 тестов на встроенном модуле `node:test`, команда `npm test`. Тесты не обращаются к базе данных. Модели подменяются через `mock.method`, поэтому закрытые методы сервисов (`#evaluateSets`, `#decide`, `#calcStep`, `#roundToEquipment`, `#selectSplit`, `#pickExercises`, `#calcStartWeight`, `#isBetter`) проверяются сценарно, через публичные методы `adapt`, `generate` и `detect`. Отдельный тест сверяет код с диаграммой классов (`npm run check:diagram`).
2. **Ручная проверка:** приложение запускалось на рабочей базе данных PostgreSQL по HTTPS и проверялось в браузере Chrome (headless) на ширинах 1440, 820 и 375 px.

Прогон 17.11.2026 (Node.js 24.15, Windows 11): **158 тестов, пройдено 158, не пройдено 0.** Полный список тестов приведён в приложении в конце документа.

В столбце «Проверка» указан файл автоматического теста из каталога `tests/` или пометка «вручную».
